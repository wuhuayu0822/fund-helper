# 基金助手

个人基金持仓监控 + 技术面买卖建议工具。提供两个版本：

- **[docs/](docs/) —— 网页版（推荐）**：纯静态网页，手机、电脑上用浏览器直接打开即可用，不需要安装任何开发者工具。目录名叫 `docs` 是因为 GitHub Pages 支持直接把仓库里的 `/docs` 文件夹发布成网站，方便部署固定网址（见下文「方式三」）。
- **[miniprogram/](miniprogram/) —— 支付宝小程序版**：需要用「支付宝小程序开发者工具」打开、编译，适合后续想正式发布成支付宝小程序的场景。

两个版本的买卖建议算法一致；数据源方面网页版已经修复为完全基于官方每日净值，**小程序版暂未同步这次修复**（还在用已下线的盘中估值接口，添加/刷新会失败），日常使用请用网页版，小程序版留作以后要发布正式小程序时再统一修复。

## 功能

- **持仓总览**：所有持仓基金的最新官方净值、较上一交易日涨跌幅、持仓市值与盈亏一览，顶部有「买入关注/观望/卖出关注」数量汇总，打开页面/切回页面时自动刷新一次。
- **基金详情**：买卖建议卡片放在最上方（一进详情页就能看到今天该怎么操作），净值走势图支持 10日/30日/3月/6月/1年 多周期切换，叠加均线的跨度与显示周期严格一一对应（10日图配10日均线，30日图配30日均线，以此类推），历史数据不够时对应均线不显示而不是显示错误的数值；MA5/MA20/MA60、均线排列、RSI(14)、乖离率、区间分位、MACD、布林带、最大回撤、年化波动率等技术指标，并附「指标参考区间与含义」说明，点开就能看懂每个指标该怎么读。
- **买卖建议**：基于历史净值的规则型信号打分（-8~+8），给出「建议关注买入区间 / 观望 / 建议关注卖出止盈」，评分旁边有文字说明分值方向，避免混淆。
- **相关资讯入口**：基金详情页提供该基金官方页面、国内外财经资讯站点的跳转链接，方便你自己结合最新消息判断——**不做自动新闻抓取或 AI 分析**（见下文说明）。
- **持仓管理**：手动添加/编辑/删除持仓，只需要填「持仓金额」「持仓盈亏」这两个从支付宝里直接就能看到的数字，程序会自动按最新官方净值反推份额和成本净值用于后续追踪，数据保存在本机浏览器（localStorage）。

**没有自动下单功能**——支付宝个人账户不提供公开的基金交易 API，出于资金安全考虑，本工具只生成参考信号，实际买卖需要你自己在支付宝 App 内手动操作。

## 网页版：如何访问

### 方式一：电脑直接双击打开（最简单，仅电脑）

直接双击 [docs/index.html](docs/index.html)，会用默认浏览器打开，功能完整可用。

### 方式二：电脑起一个本地服务，手机和电脑用同一 WiFi 访问

1. 在电脑上，进入 `docs` 文件夹，启动一个本地静态服务器。如果电脑装了 Python：

   ```bash
   cd docs
   python -m http.server 8000
   ```

   没装 Python 也可以用 Node 的 `npx serve` 等任意静态服务器，效果一样。

2. 电脑浏览器打开 `http://localhost:8000` 确认能正常显示。
3. 查看电脑的局域网 IP（Windows：打开命令提示符输入 `ipconfig`，找「IPv4 地址」）。
4. 手机连接**同一个 WiFi**，浏览器打开 `http://<电脑局域网IP>:8000`。

这种方式电脑关闭/服务器停止后，手机就打不开了，适合日常在家用。

### 方式三：部署到 GitHub Pages（推荐，固定网址，随时随地访问，不依赖电脑开机）

1. 在 [github.com](https://github.com) 新建一个仓库（Public，任意名字，比如 `fund-helper`），**不要**勾选自动生成 README（保持空仓库）。
2. 把本项目推送上去（把下面命令里的地址换成你新建仓库的地址）：

   ```bash
   git remote add origin https://github.com/<你的用户名>/<仓库名>.git
   git branch -M main
   git push -u origin main
   ```

3. 打开仓库的 **Settings → Pages**，在 "Build and deployment" 里：Source 选 `Deploy from a branch`，Branch 选 `main`，文件夹选 `/docs`，点 Save。
4. 等 1~2 分钟，网址会是：`https://<你的用户名>.github.io/<仓库名>/`。以后改了代码，`git push` 一下网站就会自动更新。

首次打开会自动写入 2 条示例持仓（华夏成长混合、招商中证白酒指数），请到「管理持仓」页替换成你自己真实持有的基金代码、份额和成本净值——数据保存在你使用的那台设备/浏览器本地，换设备或清除浏览器数据需要重新添加。

## 数据来源与合规提示

净值数据取自天天基金网的公开接口（大量开源项目都在使用，无需付费 token）：

- 历史净值（含最新一个交易日的官方净值）：`https://fund.eastmoney.com/pingzhongdata/{基金代码}.js`

网页版通过动态插入 `<script>` 标签加载这个接口（而不是 `fetch`），这样能绕开浏览器的跨域(CORS)限制，无需自建后端代理。这个接口不属于官方开放能力，仅供个人学习/自用参考；如果部署到公网长期使用，建议关注对方接口的可用性变化。

**关于"盘中实时估值"**：本项目最初还接入了 `fundgz.1234567.com.cn` 这个盘中估值接口，用来显示交易时段内不断变化的"估算净值"。但该接口已确认失效——2026年1月底，监管部门以"该类估值并非官方披露、与实际净值平均偏离可达0.8%、极端情况超过3%，容易误导投资者"为由，要求蚂蚁财富、天天基金、同花顺等主流平台关闭了"实时估值"功能，这个公开接口也随之下线（不区分协议、不区分基金代码，统一返回 404）。因此现在**只使用基金公司每个交易日收盘后公布的官方净值**，不再有盘中估算，整个 App 里"净值""涨跌幅"等字眼指的都是最新一次官方公布的数据，附带明确的净值日期。

## 买卖建议算法说明（[docs/js/indicators.js](docs/js/indicators.js)）

对每只基金的历史净值计算以下信号，命中则加/减分，参考评分总分范围 -8~+8，**分值越正越偏向"买入"，越负越偏向"卖出"，接近 0 为观望**；≥4 判定「买入关注」，≤-4 判定「卖出关注」，否则「观望」：

| 信号 | 条件 | 方向 |
| --- | --- | --- |
| RSI(14) 超卖/超买 | ≤30 / ≥70 | 买 +2 / 卖 +2 |
| 区间分位 | 近60日分位 ≤20% / ≥80% | 买 +1 / 卖 +1 |
| 乖离率(20) | ≤-5% / ≥5% | 买 +1 / 卖 +1 |
| 均线金叉/死叉 | MA5 上穿/下穿 MA20 | 买 +1 / 卖 +1 |
| 均线多空排列 | MA5>MA20>MA60（多头）/ 反序（空头） | 买 +1 / 卖 +1 |
| MACD 金叉/死叉 | DIF 上穿/下穿 DEA | 买 +1 / 卖 +1 |
| 布林带触轨 | 净值触及下轨/上轨（20日，2倍标准差） | 买 +1 / 卖 +1 |

另外还会计算**最大回撤**（历史最坏情况下的潜在亏损幅度）和**年化波动率**（净值波动剧烈程度）两个风险参考指标，仅作展示，不参与打分。详情页「指标参考区间与含义说明」里对每个指标的标准区间和该怎么解读都有说明。

这些都是纯技术面（基于历史净值）的规则型计算，**不接入任何新闻、资讯或 AI 分析服务**，也不考虑基金基本面、市场消息面、宏观环境等因素。详情页的「相关资讯」只是提供跳转链接方便你自己阅读判断，链接内容不会被抓取或参与打分。综合评分和建议**不构成投资建议**，请结合自身判断谨慎决策，注意仓位与风险控制。

由于现在用的是官方每日净值（不是盘中估算），净值和涨跌幅通常要等基金公司当天收盘后公布才会更新，白天交易时段内打开看到的还是上一个交易日的数据，这是正常现象，不是获取失败。
